2. Shared frame vocabulary

The app keeps the same underlying workspace as the presentation changes. These names can be used in future design notes and issues.

TermUse it forCurrent labels you may see
WorkspaceThe whole Keyfocus working environment: frames, navigation, command access and global controls.“Your workspace”, “Focus space”
Workspace ViewOne of the four layouts applied to the same workspace state.Operator Console, Calm Workspace, Immersive Focus, Daily Overview
FeatureA tool category that can have a frame, such as Pomodoro, Todo List, Habits, Reminders, Bookmarks or Notes.“Features”, “Tasks”, “Library”
FrameA persistent instance of a feature. It keeps its title and feature data when it leaves the active position.“Frame”, “Recent frame”, “Latest opened”
Active FrameThe single frame currently shown as the main editing surface.“Active”, “Active frame”, “Focus surface”
StackThe recency-ordered frames behind the active frame. Choosing one promotes it.“Latest frames”, “Recent frames”, “Latest opened”
Feature NavigationControls that open or promote feature frames. Use this general term across layouts.Feature Dock, Calm sidebar, Overview Navigation
Context PanelCalm Workspace’s derived priorities, reminders and playback information.“Context”, “Your priorities”, “Up next”
Overview CardA read-only summary tile in Daily Overview, with a route to the real feature.Open priorities, Pomodoro timer, Habit rhythm, Notes, Now playing, Bookmarks
Command BarThe persistent text/button control that opens commands and search.“Run a command or search…”
Command PaletteThe menu opened by the Command Bar or ⌘K; it offers create/open/search actions.“Create or search”, command rows
Workspace Settings PanelThe panel for workspace view, appearance, timer alert and bookmark import/export preferences.“Settings”
NoticeThe shared component for short messages with optional actions. Props configure presentation, placement, tone, lifetime, dismissal and screen-reader announcement.Reminder notice, undo notice, overdue notice
Empty StateExplanatory content shown when a stack, list, summary or history has no entries.“No recent frames”, “No tasks yet”, “No sessions yet”

6. Names to standardize first

  1. Use “Stack” as the common name for the same recency list called Latest Frames, Recent Frames and Latest Opened in different layouts.
  2. Use “Feature Navigation” as the umbrella name for the Operator/Immersive dock, Calm sidebar and Daily Overview top navigation. Keep the layout-specific names where we need precision.
  3. Keep “Active Frame” and “Overview Card” distinct: the frame owns editing; a card is a read-only summary route.
  4. Use “Notice” for the shared message component. Configure a persistent banner, temporary toast or inline message with props. Use announcement="assertive" when it must be announced as an alert.
